# Jezero teaching assets

The laboratory is inspired by Mars exploration. Track markings are teaching conventions, not mineral measurements or a scale map of Jezero crater.

- Robot photographs: use the existing Metropolia-branded images in `../course-info/`.
- `real-laboratory.png`: camera-only frame from Metropolia Welcome recording 21695, 24 September 2026; user/log sidebar omitted.
- `robot-directions.svg`, `octoliner-zones.svg`, `led-feedback.svg`: original explanatory diagrams. The LED diagram is functional, not a hardware-location drawing.
- Route SVGs: original schematics based on `verifications/module_1.py::sequential_navigation` and `verifications/module_4.py::python_lists`. Do not change coordinates independently of the exercise.
- Generic motor, infrared, logic, encoder and colour illustrations: retained from the previously linked course assets (`autolab-fi/lineRobot-micropython-course` and the existing course-9 media collection), now stored locally to avoid cross-course dependencies. Retain original attribution embedded in these illustrations.

Legacy HAMK photographs, Interface1.png and upload.gif elsewhere in the repository are historical assets; do not use them in the Metropolia student guide. Verification images are runtime assets and must not be removed as part of editorial cleanup.
